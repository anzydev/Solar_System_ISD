# Solar System Simulator

A lightweight 3D solar-system scene for Unity 6 using the Universal Render Pipeline.

## Open and run
1. Open `Assets/Scenes/SolarSystem.unity`.
2. Press Play.
3. Use the controls below to explore.

## Controls
- Right mouse drag: orbit the camera
- Middle mouse drag: pan
- Mouse wheel: zoom
- Click a planet or the Sun: focus and inspect it
- Home or Escape: reset the camera
- Use the on-screen **Show full system** button to return to the full view

## Included
- Sun and all eight planets
- Downloaded equirectangular surface textures
- Saturn's ring mesh and ring texture
- Animated axial rotation and orbital revolution
- Orbit paths, planet labels, distant starfield
- Planet information and camera controls

## Scale note
Distances, planet sizes and orbital speeds are stylized for visibility and an enjoyable real-time simulation. They are not a physically scaled or time-accurate ephemeris.
